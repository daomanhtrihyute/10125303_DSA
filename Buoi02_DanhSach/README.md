# Cách Chạy 
Chạy từ thư mục gốc của repo, cần cài .NET SDK 10.0:
---
dotnet run --project Buoi02_Mảng và Danh Sách Liên Kết
---
Chương trình hiện menu, nhập số thứ tự bài rồi nhấn Enter. Nhập 0 để thoát.
